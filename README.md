# OpenPhysics

OpenPhysics is a local research environment for theoretical physics, shared between researchers and LLM agents. It organizes mathematical results, their dependencies, and their review status. The OpenPhysics interface in VS Code lets you inspect derivations, revisit assumptions, and direct the agents’ work alongside your own.

**Public release coming soon.** OpenPhysics is currently in beta. Source code, the VS Code extension, and documentation will be published here.
